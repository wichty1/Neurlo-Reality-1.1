# Neurlo — personal Life OS

Private, local-first web app. All data stays in your browser (IndexedDB). No accounts, no network.

```
npm install
npm run dev      # development server
npm run build    # static build in dist/ (open via any static server, e.g. npx vite preview)
```

Full run/backup instructions will be completed in Phase 7. See PROGRESS.md for build status.
